# NLP-based Narrative Sentiment Analysis

This project performs Natural Language Processing (NLP) on generated textual narratives created from a structured dataset.  
The pipeline includes data preprocessing, narrative generation, sentiment analysis, TF-IDF feature extraction, clustering, and visualization.

##  Project Overview

This project converts structured business data into textual narratives and applies NLP techniques to analyze sentiment, extract keywords, and group similar narratives using clustering.

The goal is to simulate real-world text analytics workflows used in business intelligence and AI applications.

##  Features

- Data preprocessing using Pandas
- Narrative generation from structured dataset
- Sentiment analysis using VADER
- TF-IDF feature extraction
- KMeans clustering
- Silhouette Score evaluation
- WordCloud visualization
- Train-test split for analysis
- Export processed data to CSV

##  Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- VADER Sentiment
- TF-IDF Vectorizer
- KMeans Clustering
- Matplotlib
- WordCloud

##  Project Files

- narrative_generation_large_dataset.csv → Input dataset
- narrative_output_with_analytics.csv → Processed dataset
- train_narrative_output.csv → Training output
- test_narrative_output.csv → Testing output
- narrative_sentiment_analysis.ipynb → Main notebook

##  Workflow

1. Load dataset
2. Preprocess data
3. Generate narratives
4. Perform sentiment analysis
5. Extract features using TF-IDF
6. Apply KMeans clustering
7. Evaluate using Silhouette Score
8. Generate WordCloud visualization
9. Save results to CSV

##  Output

- Sentiment scores for each narrative
- Cluster labels
- Keyword features
- Visualization using WordCloud
- Processed CSV files
